# Modern Dalamud Interface Review

The 0.4 interface redesign used two current IcarusXIV plugins as product-design
references. No code or visual assets were copied.

## Encore patterns reviewed

Encore presents a large preset library through clear organization tools:
collapsible grouping, search, sorting, favourites, icons, and direct one-click
actions. The relevant lesson for Sell Everything is that the primary action
should remain obvious while large collections are moved into focused, searchable
surfaces.

Applied to Sell Everything:

- One prominent Start or Resume action.
- Separate Queue and Protected Items workspaces.
- Search and state filtering instead of one oversized table.
- Current state and recent activity kept visible on the dashboard.

## Character Select+ patterns reviewed

Character Select+ combines richer profile management with a deliberately small
Quick Switch surface. Its organization features include search, tags, favourites,
preview-driven identification, and drag-and-drop ordering.

Applied to Sell Everything:

- A compact Overview for frequent actions.
- Detailed management moved behind tabs.
- Clear item identity, quality, decision, price, and status columns.
- Settings grouped by user intent rather than implementation order.

## Resulting interface principles

1. Frequent actions are available immediately.
2. Detail appears progressively through tabs and tables.
3. Search and filters reduce scanning cost.
4. State is communicated with both text and color.
5. Destructive controls are visually distinct.
6. Faults remain visible and have an explicit recovery action.
